Web To OpenAPI 设置

配置本地 OpenAPI 服务的监听地址、端口与浏览器行为。配置保存在扩展存储中; 地址/端口保存后扩展会自动重新加载, 浏览器行为保存后立即下发给本地服务生效。

127.0.0.1 = 仅本机可访问(推荐); 0.0.0.0 = 允许局域网/其他设备访问(请注意安全风险)。
默认 8090。确保该端口未被其他程序占用。
浏览器行为
控制本地服务驱动浏览器(Edge / Chrome)时怎么开页面、以及页面留多久。 保存在扩展存储中并下发给本地服务, 立即生效, 无需重启浏览器。
浏览器没有"完全隐藏窗口"的能力, tab 是"看起来什么都没发生"的最优解; 代价是后台标签会被调度节流(渲染重的页面如谷歌会变慢)。
window-corner 用右下角独立小窗替代 1280×900 大窗, 纯粹是为了"不挡屏幕": 小窗不抢焦点, 任务完成自动消失。注意实测它**不能提速**——翻译耗时取决于百度 AI 生成 与页面加载, 隐藏状态只拖慢冷启动约 1.4s、复用时无差异; 浏览器窗口铺满屏幕时小窗被遮挡, 页面可能掉 hidden, 但端到端仍 3-5s。
需要登录/验证时页面会自动切到前台。
任务完成后页面留多久再关。180(默认) = 3 分钟内再次调用复用同一页面、不重新加载 (翻译接口约 4s → 2s); 0 = 每次调用结束就关(旧行为, 每次都重新加载)。 只影响服务自己开的那个后台标签。

百度搜索默认参数
保存在扩展存储中并下发给本地服务。调用 GET /api/v1/search/baidu 时, 请求显式传的参数优先, 未传的字段自动套用此处默认。留空 = 不限制。
Google 搜索默认参数
保存在扩展存储中并下发给本地服务。调用 GET /api/v1/search/google 时, 请求显式传的参数优先, 未传的字段自动套用此处默认。留空 = 不限制。
使用前提
  1. 已通过 edge://extensions 或 chrome://extensions(开发者模式) 加载本扩展 —— 仅需一次,Edge / Chrome 通用。
  2. 已运行一次 host 安装脚本 install-host.ps1 —— 注册 native messaging(Edge 与 Chrome 两个注册表键会一起写上), 仅需一次。
  3. 浏览器已登录 scnet.cn(余额查询需要; 登录态不跨浏览器共享)。
