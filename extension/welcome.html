Web To OpenAPI 已安装

将网页能力封装为本地 OpenAPI HTTP 服务. SCNet 余额查询只是第一个示例接口, 未来会加入更多 Web 内容接口, 成熟后还将支持大模型定制 API.

这是什么

本扩展随附一个本地服务 (native host). 它驱动 Edge 浏览器, 把网页上的数据/操作 暴露成一组可通过 HTTP 调用的 OpenAPI 接口. 无需任何命令行安装 —— 装好扩展即已就绪.

使用步骤

  1. 在扩展「选项」里配置监听地址与端口 (默认 127.0.0.1:8090).
  2. 本地服务地址: http://127.0.0.1:8090
  3. 示例接口: GET /api/v1/scnet/balance (需 Edge 已登录 scnet).
  4. 接口目录: GET /api/v1/tools · 接口文档: GET /docs · 服务说明: GET /openapi.json

使用前提

  1. 已通过 edge://extensions (开发者模式) 加载本扩展一次.
  2. 已运行一次 install-host.ps1 注册 native messaging (一次即可).
  3. Edge 已登录对应网站 (如 scnet.cn) 才能取到相关网页数据.
